# موقع نبيل ناجي نبيل

نسخة أولى ثابتة وعملية من الموقع الشخصي ومعرض الأعمال، مبنية بملفات HTML وCSS وJavaScript منفصلة، دون ادعاء وجود لوحة إدارة أو قاعدة بيانات أو خدمة بريد غير موصولة.

## التشغيل

يتطلب المشروع Node.js 18 أو أحدث. من داخل مجلد المشروع شغّل:

```bash
node server.js
```

ثم افتح `http://localhost:3000`.

## هيكل الملفات

- `index.html` — الهيكل والمحتوى العربي والإنجليزي.
- `styles.css` — التصميم المتجاوب، الوضع الداكن، حالات التركيز وتقليل الحركة.
- `script.js` — تبديل اللغة والمظهر، حفظ الاختيارات محليًا، حالة نموذج التواصل، وصفحات الشروط والخصوصية.
- `db.js` — قاعدة بيانات IndexedDB حقيقية داخل المتصفح لحفظ المحتوى والرسائل على الجهاز.
- `admin.html` و`admin.js` — صفحة إدارة محلية لتعديل المحتوى ورؤية الرسائل وتصدير/استيراد نسخة JSON.
- `server.js` — خادم Node صغير للمعاينة مع دعم مسارات `/terms` و`/privacy`.
- `public/manus-routes.json` — المسارات الفعلية للموقع.
- `assets/logo.svg` — علامة الموقع المؤقتة.
- `TODO.md` — ما تم إنجازه وما ينتظر المرحلة التالية.

## ما يعمل فعليًا

- العربية افتراضيًا مع RTL، والتبديل إلى الإنجليزية مع LTR.
- الوضع الفاتح والداكن محفوظان في `localStorage`.
- تصميم متجاوب مع الهاتف والكمبيوتر، وتنقل بلوحة المفاتيح، ودعم تفضيل تقليل الحركة.
- عرض بيانات نبيل الواقعية فقط: التعليم، المجالات، المهارات بوصف «قيد التعلم»، وسائل التواصل، وحالات فارغة للمحتوى غير المتوفر.
- روابط البريد والهاتف وواتساب والمنصات الاجتماعية تعمل كروابط خارجية.
- قسم المشاريع يقرأ المستودعات العامة مباشرة من GitHub للحساب `nabelnage9-wq` عبر GitHub API، مع رابط مباشر للحساب في حال تعذر التحميل.
- تمت إضافة قسم مستقل لمهارات البرمجة والتقنيات المستخدمة. يعرض HTML وCSS وJavaScript وSQL وPython بوصفها قيد التعلم، ويذكر تقنيات الموقع الفعلية مثل IndexedDB وGitHub API والتصميم المتجاوب وإمكانية الوصول وRTL/LTR.
- نموذج التواصل تجريبي: يمنع الإرسال الحقيقي ويعرض رسالة توضيحية بدل الادعاء بأنه أرسل بريدًا.
- نموذج التواصل يحفظ الرسائل فعليًا داخل IndexedDB على الجهاز، لكن لا يرسلها إلى البريد.
- صفحة `/admin` تعدّل المحتوى وتعرض الرسائل المحفوظة وتدعم النسخ الاحتياطي JSON.
- صفحة `/admin` تحتوي أيضًا على نماذج فارغة لإضافة الشهادات والخبرات والكورسات والفيديوهات والمقالات، وتحفظ كل نوع في مجموعة مستقلة داخل IndexedDB مع إمكانية الحذف.
- زر السيرة الذاتية غير ظاهر لأن ملف PDF لم يُرفع ولم تتم الموافقة على نشره.

## ما يحتاج مرحلة لاحقة

هذه قاعدة بيانات محلية داخل متصفح الجهاز وليست قاعدة بيانات خادم. البيانات لا تتزامن بين الأجهزة، وقد تُحذف عند مسح بيانات الموقع أو تغيير المتصفح؛ لذلك استخدم زر تصدير JSON للنسخ الاحتياطي. لا توجد حماية دخول حقيقية في لوحة الإدارة المحلية، فلا تحفظ فيها بيانات حساسة.

قاعدة بيانات وخادم حقيقيان للحسابات ولوحة الإدارة والصلاحيات وسجل التغييرات، خدمة بريد أو رسائل، تخزين ملفات خاص، ربط المتجر والدفع والكورسات والبث والماليات والتكاملات الاجتماعية تحتاج مرحلة خادم لاحقة. يجب عدم إضافة أي من هذه الوظائف على الواجهة قبل ربط الخدمة والتحقق من الأمان والصلاحيات.

تمت إضافة صورة `profile.jpg` الأصلية التي قدمها المستخدم إلى `assets/profile.jpg` واستخدامها في بطاقة الملف الشخصي دون توليد وجه جديد أو تغيير الملامح.
